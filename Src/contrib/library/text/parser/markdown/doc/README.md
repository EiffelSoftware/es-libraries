# Documentation

This directory contains comprehensive documentation for the Markdown parser library.

## Documentation Files

- **[ARCHITECTURE.md](ARCHITECTURE.md)** - Architecture overview, AST design, visitor pattern, and parser strategy
- **[FEATURES.md](FEATURES.md)** - Complete feature list with implementation status
- **[USAGE.md](USAGE.md)** - Usage guide with examples for parsing, rendering, and custom visitors

## Quick Start

1. Read [USAGE.md](USAGE.md) for basic usage examples
2. Check [FEATURES.md](FEATURES.md) to see what's implemented
3. Review [ARCHITECTURE.md](ARCHITECTURE.md) to understand the design

## Documentation Structure

The documentation is organized as follows:

- **Getting Started**: See the main [README.md](../README.md) in the project root
- **Usage**: [USAGE.md](USAGE.md) - How to use the library
- **Architecture**: [ARCHITECTURE.md](ARCHITECTURE.md) - Design and implementation details
- **Features**: [FEATURES.md](FEATURES.md) - Complete feature status
