For many XEBRA projects, the environment variable XEBRA_LIBRARY must be set to the absolute path to ./eiffel_projects/library

Windows:
set XEBRA_LIBRARY="%ISE_LIBRARY%\framework\web\xebra\eiffel_projects\library"

Powershell
$env:XEBRA_LIBRARY="$env:ISE_LIBRARY\framework\web\xebra\eiffel_projects\library

Unices
set XEBRA_LIBRARY="$ISE_LIBRARY/framework/web/xebra/eiffel_projects/library
